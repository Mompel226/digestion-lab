# Where these images came from

Every image in this folder was taken from Dr Mompel's own IGCSE Topic 7 lesson
PowerPoints, so that the simulation shows students the same figures they saw in class.
They are reproduced here for that teaching purpose. If any image needs to be replaced,
drop a new file with the same name into this folder and it will appear automatically.
